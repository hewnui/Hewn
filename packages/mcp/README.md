# @hewnui/mcp

Read-only Model Context Protocol (stdio) server that lets AI coding tools list and inspect Hewn components, themes, tokens, and install commands.

**Coming soon.** Not published to npm yet — there is no public install command. The package stays private in this workspace until a later release.

Bin (monorepo): `hewn-mcp`.

## Run from this monorepo (contributors)

```bash
pnpm --filter @hewnui/mcp build
node packages/mcp/dist/cli.js
```

Docs: https://hewnui.dev/docs/mcp
