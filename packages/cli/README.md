# hewnui

Copy typed Hewn React components into your project and lint against your theme: `hewn init`, `add`, `theme`, `lint`.

Bins: `hewn` and `hewnui`. Part of [Hewn](https://hewnui.dev).

## Install

```bash
npx hewnui@latest init
npx hewnui@latest add button
npx hewnui@latest theme
npx hewnui@latest lint
```

Requires Node ≥ 22. Docs: https://hewnui.dev/docs/cli
