Hewn grows in phases. The free core stays free — Pro pays for
composition, not for primitives.

## Shipped

- **Foundation** — semantic OKLCH tokens, theme/mode/material/motion providers
- **Reference components** — Button, fields, Checkbox, Switch, Dialog, Select, Tabs, Table
- **Theme breadth** — six curated packs, tinted glass, Theme Lab
- **Rich free core** — DatePicker, Combobox, Menu, Toast, Drawer, Progress, Skeleton, DataTable
- **Distribution** — npm packages (`@hewnui/ui`, `@hewnui/motion`, `@hewnui/themes`), the `hewnui` CLI, the static registry, and the shadcn registry
- **Theme platform** — Theme Studio, Figma kit, charts, `/llms.txt`

### Next

- **AI schema v1** — `/ai/index.json` (live)
- **`@hewnui/mcp`** — local stdio MCP — coming soon (not on npm yet)
- **AI theme generation** — BYOK + offline heuristics in Theme Studio
- **Hewn Pro** — application blocks and pages — [join the waitlist](/pro#waitlist)

AI agents can start from [`/llms.txt`](/llms.txt) for a curated docs index, or
[`/ai/index.json`](/ai/index.json) for per-component machine-readable schema
(props, states, keyboard, tokens, install, examples).

## Free vs Pro

Free: all core components (including charts), six theme packs, glass, motion,
documentation, the curated Figma kit, the static registry, `/llms.txt`, and
the npm packages and CLI.

Pro (in development): application blocks and pages built on the free core —
[join the waitlist](/pro#waitlist). Advanced theme authoring and pack exporters
are planned for Pro.

Pro is in development. Pricing and access details are undecided. Join the
[waitlist](/pro#waitlist) to hear first when something is ready to try.
