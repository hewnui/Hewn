Built on React Aria TextField with a Group and reveal button. Defaults to
masked input; the toggle swaps to plain text without leaving the field chrome.

<PasswordFieldDemo />

## Usage

```tsx
import { PasswordField } from "@hewnui/ui";

<PasswordField label="Password" placeholder="Enter passphrase" />
```

## Variants

`outline` (default), `filled`, `flushed`, and `glass`.

## States

- Description helper text
- Invalid + `errorMessage`
- Disabled
- `defaultVisible` starts revealed

## Accessibility

- Toggle button has show/hide accessible names
- Hit target is at least 40×40px
- Label and error association from React Aria
