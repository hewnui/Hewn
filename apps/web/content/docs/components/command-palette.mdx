CommandPalette pairs a dialog trigger with React Aria Autocomplete and Menu.
Filter grouped commands, show shortcut hints, and wire an optional global hotkey.

<CommandPaletteDemo />

## Usage

```tsx
import { useState } from "react";
import {
  Button,
  CommandPalette,
  CommandPaletteGroup,
  CommandPaletteInput,
  CommandPaletteItem,
  CommandPaletteList,
  CommandPaletteTrigger,
  commandPaletteHotkeyLabel,
  useCommandPaletteHotkey,
} from "@hewnui/ui";

const [isOpen, setOpen] = useState(false);
// Docs search owns ⌘/Ctrl+K on this site — demos use J instead.
useCommandPaletteHotkey({ key: "j", onOpenChange: setOpen });

<CommandPaletteTrigger isOpen={isOpen} onOpenChange={setOpen}>
  <Button>Commands</Button>
  <CommandPalette>
    <CommandPaletteInput />
    <CommandPaletteList>
      <CommandPaletteGroup heading="Actions">
        <CommandPaletteItem
          id="new"
          shortcut={commandPaletteHotkeyLabel("n")}
          textValue="New file"
        >
          New file
        </CommandPaletteItem>
      </CommandPaletteGroup>
    </CommandPaletteList>
  </CommandPalette>
</CommandPaletteTrigger>
```

## States

- Loading — `CommandPaletteList isLoading` shows a polite status with spinner
- Empty — filtered Menu `renderEmptyState` via `emptyLabel`
- Disabled — `CommandPaletteItem isDisabled`

## Accessibility

- Dialog role with an accessible name; focus moves into the search field on open
- Escape and outside click dismiss; focus returns to the trigger
- Arrow keys move between commands; Enter activates; typeahead filtering via Autocomplete
- Shortcut hints use the `Keyboard` element; icons are presentational
- Reduced motion: enter/exit transitions fall back with `motion-reduce`

## Hotkey on this page

Press Ctrl+J (⌘J on Mac) on this page. Ctrl/⌘K is taken by docs search here; in
your app the hook defaults to ⌘K / Ctrl+K.
