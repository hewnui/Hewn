Built on React Aria TextField. Labels sit above the control with optional
helper and error text below.

<TextFieldDemo />

## Usage

```tsx
import { TextField } from "@hewnui/ui";

<TextField label="Email" type="email" placeholder="you@studio.dev" />
```

## Variants

`outline` (default), `filled`, `flushed`, and `glass`.

Under the global **glass** material, boxed variants pick up tinted frost and
refraction. `flushed` stays underline-only so the bottom edge remains legible.

## Sizes

`sm`, `md` (default), and `lg`.

## States

- Description helper text
- Invalid + `errorMessage`
- Disabled

## Accessibility

- Label association through React Aria
- Error text connected via field semantics
- Keyboard focus ring on the input
