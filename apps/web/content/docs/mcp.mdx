`@hewnui/mcp` is a read-only Model Context Protocol server over stdio. When it
ships, AI coding tools will be able to list and inspect free components without
scraping the docs site.

**Coming soon.** The package is not published to npm yet — there is no install
command today. Until then, use [`/llms.txt`](/llms.txt) and
[`/ai/index.json`](/ai/index.json).

## Planned tools

| Tool | Purpose |
|------|---------|
| `list_components` | Registry items |
| `search_components` | Substring search |
| `get_component` | Registry row + AI schema JSON |
| `get_install_command` | npm + CLI install strings |
| `get_theme` | Curated packs (or one pack by id) |
| `get_tokens` | Tokens for a component or theme pack |

## Contributors (monorepo only)

The workspace package can be built from this repository after `pnpm generate`.
That path is for contributors developing the server — not a public install.

```bash
pnpm --filter @hewnui/mcp build
node packages/mcp/dist/cli.js
```

Set `HEWN_ROOT` if the server cannot find the workspace root.
