`@hewnui/mcp` exposes a read-only Model Context Protocol server over stdio.
AI coding tools can list and inspect free components without scraping the docs
site.

The package is **private for the 0.1.0 release** and is not published to npm yet.

## Run

{/* Install command strings: packages/docs-metadata/src/distribution.ts */}

From the monorepo (after `pnpm generate` so registry + AI JSON exist) —
contributors only:

```bash
pnpm --filter @hewnui/mcp build
node packages/mcp/dist/cli.js
```

Set `HEWN_ROOT` if the server cannot find the workspace root.

## Tools

| Tool | Purpose |
|------|---------|
| `list_components` | Registry items |
| `search_components` | Substring search |
| `get_component` | Registry row + AI schema JSON |
| `get_install_command` | npm + CLI install strings |
| `get_theme` | Curated packs (or one pack by id) |
| `get_tokens` | Tokens for a component or theme pack |

## Cursor example

```json
{
  "mcpServers": {

      "args": ["packages/mcp/dist/cli.js"],
```
