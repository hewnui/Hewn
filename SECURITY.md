# Security Policy

## Supported versions

Security fixes land on the default `main` branch of this repository.

## Reporting a vulnerability

Please report security issues **privately** through GitHub Security Advisories for this repository:

[https://github.com/hewnui/Hewn/security/advisories/new](https://github.com/hewnui/Hewn/security/advisories/new)

Do not open a public issue for vulnerabilities that could be exploited. Include steps to reproduce, affected packages or paths, and impact when you can. We will acknowledge the report and coordinate a fix and disclosure.
